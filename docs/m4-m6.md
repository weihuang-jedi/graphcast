### 2. Multi-Mesh Hierarchy Levels (`hierarchy_levels`)

In GraphCast, the multi-mesh encoder/decoder hierarchy must match the finest mesh level:

* **M4:** `hierarchy_levels: [4, 3, 2, 1, 0]`
* **M6:** `hierarchy_levels: [6, 5, 4, 3, 2, 1, 0]`

### 3. Slurm GPU Memory & Batch Size Optimization

Because the graph size scales from $81\text{K}$ to $1.31\text{M}$ node-level points, memory usage during backpropagation will increase significantly.

Update your **`training.slurm`** script:

1. **Enable PyTorch CUDA Expandable Segments:** Prevents memory fragmentation during large graph message passing.
2. **Reduce Per-GPU Batch Size & Use Gradient Accumulation:** Set `batch_size: 1` and `accumulate_grad_batches: 4` in PyTorch Lightning.

**`training.slurm`:**

```bash
#!/bin/bash
#SBATCH --job-name=training_m6
#SBATCH --account=epic
#SBATCH --export=NONE
#SBATCH --gres=gpu:h100:1
#SBATCH --mem=256G                  # Increased host RAM for M6 Zarr caching
#SBATCH --nodes=1
#SBATCH --output=log.training_m6_%J.out
#SBATCH --partition=u1-h100
#SBATCH --qos=gpuwf
#SBATCH --time=12:00:00

set -x

if [ -z "$CONDA_PREFIX" ]; then
   EAGLEhome=/scratch5/purged/Wei.Huang/src/EAGLE
   source ${EAGLEhome}/conda/etc/profile.d/conda.sh
   eval "$(mamba shell hook --shell bash)"
   mamba activate anemoi
fi

export PYTHONUNBUFFERED=1
export PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True

cd /scratch4/NAGAPE/epic/Wei.Huang/src/starviewergraphcast/src

time PYTHONPATH=. python training/training.py -c config_standard.yaml

```

### 5. Regridder KD-Tree Search Radius (`reconstruct_forecast_latlon.py`)

At M6 resolution ($\approx 100\text{ km}$ node spacing), the average distance between icosahedral nodes and 0.25° lat-lon grid points shrinks significantly.

In `rollout/reconstruct_forecast_latlon.py`, update the Gaussian smoothing variance $\sigma$ for the 4-nearest-neighbor search:

```python
# M4 Mesh Variance: sigma = 0.05
# M6 Mesh Variance: sigma = 0.0125 (tighter Gaussian weighting for 100km mesh)
weights = np.exp(-(dists**2) / (2 * 0.0125**2))
weights /= weights.sum(axis=-1, keepdims=True)

```
